# Ece Eren — Portfolio

Personal portfolio of Ece Eren, Full Stack & AI Developer.

**Live:** https://erenece.github.io

## Stack
- Plain HTML and CSS, no framework and no build step
- One small JavaScript file for the cursor trail effect
- Turkish (`/`) and English (`/en/`) versions
- Hosted on GitHub Pages

## Structure
```
index.html              Home (TR)
en/index.html           Home (EN)
projeler/*.html         Project pages (TR)
en/projects/*.html      Project pages (EN)
assets/css/style.css    All styles
assets/js/cursor.js     Cursor trail effect
assets/img, video, cv   Images, demo videos, resumes
```

## Run locally
Paths start from the site root (`/assets/...`), so open it through a local server:

```bash
python -m http.server 5500
```

Then visit http://localhost:5500
